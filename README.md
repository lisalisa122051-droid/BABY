# WhatsApp Bot Multi-Device

Bot WhatsApp berbasis Node.js menggunakan Baileys MD (elaina-baileys) dengan 1000+ fitur dan sistem database terintegrasi.

## ✨ Fitur Utama

- ✅ **Multi-Device Support** - Bisa login di banyak perangkat
- ✅ **Button & List Menu** - Menu interaktif dengan button dan list
- ✅ **Database User** - Simpan data user, group, premium
- ✅ **1000+ Commands** - Fitur lengkap berbagai kategori
- ✅ **Auto Register** - User otomatis terdaftar saat pertama chat
- ✅ **Thumbnail Video** - Menu dengan thumbnail video MP4
- ✅ **Quoted Message** - Support reply/quoted message
- ✅ **Multi Prefix** - Support prefix `.`, `!`, `/`
- ✅ **Auto Read & Typing** - Auto read message dan typing indicator
- ✅ **Runtime Statistics** - Monitor performa bot
